Arquitectura Anti-Hack & Privacidad

Diseñado desde la raíz para proteger tu negocio: evita la clonación de licencias y nunca expone tu SQL Server a ataques directos de internet.

📱

Hardware ID Binding

Cada instalación genera un identificador único ligado al hardware físico del celular (CEL-XXXX). Una clave activada en un teléfono jamás funcionará en otro dispositivo.

🔒

Hermes AOT Bytecode

En lugar de empaquetar JavaScript en texto plano, el motor Hermes compila el código en binario nativo optimizado, cerrando la puerta a herramientas de cracking como APKTool o JADX.

🛡️

Aislamiento por Bridge

El celular nunca se conecta directamente al puerto 1433 de SQL Server. La comunicación pasa por el microservicio seguro local, evitando exponer la base de datos a ataques DDoS o inyecciones.

✨

Anti-Tampering Seal

La app valida la integridad del almacenamiento local en cada inicio. Si se detecta un intento de adulteración con herramientas de depuración o root, se revierte automáticamente a Modo DEMO protegido.

Política de Privacidad & Seguridad

1. Privacidad de Datos y Conexión Directa: Mu Manager PRO no recopila, no comercializa ni comparte con terceros ninguna información confidencial ni bases de datos de tus jugadores. Las conexiones a SQL Server se efectúan en forma directa contra tu conector privado.

2. Telemetría de Licencia y Diagnóstico: La aplicación envía pings periódicos transparentes hacia el gateway que contienen únicamente el identificador de hardware (HWID), la versión de la app instalada y el estado de la licencia, con el único fin de activar funciones PRO, validar autorizaciones y notificar actualizaciones críticas.

3. Permisos en el Sistema: La aplicación solicita exclusivamente los permisos necesarios declarados en el paquete: INTERNET y ACCESS_NETWORK_STATE para enlace con el servidor, VIBRATE para alertas de interfaz y permisos de almacenamiento para exportar backups locales.

Términos de Uso

1. Ámbito de Uso: Mu Manager PRO está diseñado exclusivamente para la administración legítima de servidores de juegos MU Online bajo el control y consentimiento del administrador.

2. Licenciamiento: Cada clave de activación emitida es intransferible y está asociada al dispositivo del usuario. Queda prohibido cualquier intento de descompilación, ingeniería inversa o elusión de las medidas de protección criptográfica.

3. Responsabilidad: El administrador es responsable de la seguridad de sus credenciales SQL Server y de mantener copias de seguridad de sus bases de datos.
