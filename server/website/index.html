Diseño de Seguridad y Privacidad

Arquitectura de Seguridad & Privacidad

Diseñado para proteger la administración de tu servidor: vinculación estricta de licencias y opciones de aislamiento local para SQL Server.

📱

Hardware ID Binding

Cada instalación genera un identificador anónimo derivado del dispositivo. La validación se gestiona de forma centralizada en el servidor para evitar activaciones concurrentes o no autorizadas.

🔒

Hermes AOT Bytecode

El motor Hermes precompila la lógica de la aplicación a bytecode optimizado (AOT), mejorando sustancialmente el rendimiento de arranque y la integridad de ejecución en el cliente móvil.

🛡️

Aislamiento por Servicio

La aplicación interactúa a través de APIs autenticadas (Gateway HTTPS o Conector local). Con el conector opcional, SQL Server escucha exclusivamente en localhost, sin abrir puertos de base de datos hacia internet.

✨

Almacenamiento Autenticado

El resguardo local de credenciales utiliza cifrado autenticado (AES-256 / HMAC). Ante discrepancias de integridad o expiración de sesión, el acceso se bloquea protegiendo la base de datos.

Instalación y Configuración en 4 Pasos

Configura tu ecosistema móvil en menos de 5 minutos siguiendo este procedimiento seguro.

1

Descargar e Instalar APK

Descarga MuManagerPro.apk en tu Android. Si el sistema te lo solicita, autoriza "Instalar aplicaciones desconocidas" únicamente para tu navegador de confianza.

2

Conexión por Gateway HTTPS

Abre la app, ingresa a Conexión y configura tus credenciales. La aplicación se comunicará a través de la pasarela HTTPS segura de manera autenticada.

3

Conector Local (Aislamiento Total)

Activar tu Licencia PRO

Ve a Config ➔ Licencia, consulta tu identificador de dispositivo, ingresa la clave asignada por el administrador y disfruta de la suite completa.

Política de Privacidad & Seguridad

1. Tratamiento de Credenciales y Datos SQL: Mu Manager PRO no comercializa ni comparte con terceros ninguna información confidencial ni bases de datos de tus servidores. Las credenciales de base de datos viajan cifradas en tránsito (TLS) hacia el Gateway o Conector seleccionado exclusivamente para ejecutar las operaciones solicitadas por el usuario. En el dispositivo, las claves de acceso se resguardan en almacenamiento cifrado autenticado (AES-256 / HMAC-SHA256).

2. Telemetría de Licenciamiento y Seguridad: Para la validación de licencias, control de accesos concurrentes y protección contra abusos, la aplicación transmite de forma periódica al gateway: el identificador de hardware (HWID anónimo), la versión instalada, el estado de la licencia, marca y modelo del dispositivo, indicador de entorno emulado y token de sesión. Esta información se utiliza exclusivamente para fines operativos de autorización, límites de tasa (rate limiting) y prevención de fraudes.

3. Declaración de Permisos: La aplicación declara en su manifiesto únicamente: INTERNET y ACCESS_NETWORK_STATE (para comunicación segura con el gateway/conector), VIBRATE (retroalimentación háptica en la interfaz) y READ/WRITE_EXTERNAL_STORAGE (acotados a Android 9 o inferior mediante maxSdkVersion="28" para la exportación e importación de respaldos locales; en Android 10+ se utiliza almacenamiento privado scoped). La aplicación no solicita ni accede a cámara, contactos, micrófono, ubicación ni mensajes SMS.

Términos de Uso

1. Ámbito de Uso: Mu Manager PRO está diseñado exclusivamente para la administración legítima de servidores de juegos MU Online bajo el control y consentimiento del administrador.

2. Licenciamiento: Cada clave de activación emitida es intransferible y está asociada al dispositivo del usuario. Queda prohibido cualquier intento de descompilación, ingeniería inversa o elusión de las medidas de protección criptográfica.

3. Responsabilidad: El administrador es responsable de la seguridad de sus credenciales SQL Server y de mantener copias de seguridad de sus bases de datos.
