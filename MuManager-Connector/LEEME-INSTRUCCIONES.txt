================================================================
  MU MANAGER PRO — GUÍA DE INICIO RÁPIDO DEL CONECTOR (WINDOWS)
================================================================

Este módulo permite comunicar de forma segura y privada la app
"Mu Manager PRO" con tu base de datos SQL Server (MuOnline).

PASO 1:
Copia esta carpeta en el servidor o VPS donde se ejecuta SQL Server.

PASO 2:
Haz clic derecho en "MuManager-Connector.exe" y selecciona "Ejecutar como Administrador".
(Al ejecutarse como Administrador, el conector autoriza automáticamente el puerto 3001 en el Firewall de Windows).
Se abrirá la consola indicando que el servicio está activo en el puerto 3001.

PASO 3:
En la aplicación móvil MuManager PRO:
1. Ve a "Config" (ícono de engranaje).
2. En "IP del Servidor" ingresa la IP de tu servidor o VPS.
3. Ingresa tu usuario SQL y contraseña de base de datos.
4. Presiona "Guardar y Probar Conexión".
